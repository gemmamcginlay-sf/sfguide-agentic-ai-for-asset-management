# Barclays ORBIT — Project Context

## What This Is

This is the **SAM (Simulated Asset Management)** demo, which we are transforming into **Barclays ORBIT** — an investment intelligence platform. The original SAM demo was built by Mats Stellwall at Snowflake.

## Current State: Original SAM v2 (Untouched)

The codebase is currently the original SAM demo with no modifications. It should deploy successfully as-is. Once confirmed working, we will transform it into ORBIT following the phased plan in `docs/ORBIT_TRANSFORMATION_PLAN.md`.

## Important Regional Constraints

- AWS EU-West-1 (Ireland) region
- Some Cortex models may need cross-region routing (`CORTEX_ENABLED_CROSS_REGION = 'ANY_REGION'` is set in setup.sql)
- Snowflake Public Data Cortex Knowledge Extension is NOT available in this region
- Python workspace execution requires a compute pool

## Architecture Summary (Current SAM v2)

- **8 Cortex Agents** — Portfolio, Research, Sales, Executive, Risk, Operations, Credit, PE
- **17 Semantic Views** — Cortex Analyst text-to-SQL models
- **12+ Cortex Search Services** — RAG over documents and transcripts
- **36 Agent Skills** — Multi-step guided workflows
- **60+ Data Tables** — Real market data + synthetic portfolios/documents
- **Build time:** ~15-20 minutes via workspace_main.py

## Data: What's Real vs Synthetic

### Real (from Snowflake Public Data Paid)
- Stock prices (14,000+ securities, near-real-time)
- SEC financial statements (XBRL from 10-K/10-Q)
- SEC filing full text (10-K, 10-Q, 8-K)
- Earnings call transcripts (9,000+ companies)
- Revenue segments (geographic/business)
- Insider trading (Form 4)
- Institutional holdings (13F)
- Treasury yields, FX rates, policy rates
- Economic indicators (FRED)
- GHG emissions (Climate Watch)

### Synthetic (generated by the Python build)
- 11 portfolios + daily positions
- Transactions, ESG scores
- All PDF documents (broker research, memos, policies)
- PE deal pipeline, credit portfolio, borrowers
- Client data, middle office operations
- Morning briefings, signals (AI-generated from real data)

### Derived (maths on real data — defensible for demos)
- Returns (from real prices)
- Covariance matrix (from real returns)
- Factor exposures (from real prices + real financials)
- Attribution (Brinson decomposition on real benchmark returns)
- Monte Carlo simulations (from real covariance)
